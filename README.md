## 🌟 Overview

**SkillDad Platform** is a full-featured online education and technical knowledge-sharing platform. Built for performance, responsiveness, and accessibility, the portal provides comprehensive roadmaps, video tutorials, digital magazines, interactive developer tools, and an IT terminology glossary.

---

## 🚀 Key Modules & Pages

- 🏠 **Main Landing (`index.html`):** Interactive hero section, featured courses, categorized tutorials, real-time statistics counter, and structured learning paths.
- 📚 **Digital Magazine (`magazine.html`):** In-depth technical articles, modern card layout, and tag-based categorization.
- 🎥 **Video Training Hub (`videos.html`):** Integrated video streaming with automated synchronization with YouTube and Aparat channels.
- 🛠️ **Developer Toolbox (`toolbox.html`):** Interactive client-side developer utilities and productivity widgets.
- 🔧 **Troubleshooting Portal (`troubleshoot.html`):** Step-by-step diagnostic and problem-solving guides for developers.
- 📖 **Tech Glossary (`glossary.html`):** Fast search and filter glossary for programming concepts and computer science terminology.
- 📬 **Contact & Inquiry (`contact.html`):** Dynamic message submission engine with validation and structured logging.

---

## 🛠️ Tech Stack

- **Frontend:** Semantic HTML5, Glassmorphism & Modern CSS3, Vanilla JavaScript (ES6+)
- **Backend Services:** Modular PHP REST API endpoints for analytics and message dispatching
- **Local Dev Environment:** Python lightweight HTTP server (`server.py`)
- **SEO & Social Optimization:** Dynamic OpenGraph metadata, structured schema, `sitemap.xml`, and `robots.txt`

---

## 💻 How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/hassnasgari/SkillDad-Platform.git
   ```
2. Launch with Python:
   ```bash
   python -m http.server 8000
   ```
3. Open `http://localhost:8000` in your browser.
